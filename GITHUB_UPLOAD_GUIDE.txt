Panduan Upload ke GitHub

1. Buka terminal di folder project ini.

2. Jalankan:
   git init
   git add .
   git commit -m "Initial speedtest gaming analyzer"

3. Buat repository kosong di GitHub.

4. Hubungkan remote:
   git remote add origin https://github.com/USERNAME/NAMA_REPO.git

5. Upload:
   git branch -M main
   git push -u origin main

Catatan:
- Jangan upload node_modules.
- File .gitignore sudah disiapkan.
- Kalau ingin web public dengan domain, tetap butuh VPS/hosting Node.js.
- Kalau hanya ingin dipakai lokal atau komputer lain satu Wi-Fi, cukup jalankan BUKA_SPEEDTEST.bat.
